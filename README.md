Para poder correr la práctica 3 debemos de abrir una terminal como administrador en dirección de la carpeta donde se clono el repositorio y ponemos lo siguiente en la terminar:

npm run dev

De ahí nos arrojará una url que podremos poner en nuestro navegador para poder visualizar nuestra pagina de busqueda, tanto para buscar libros y/ tv shows como también para crear usuarios nuevos
o hacer login con usuarios ya existentes.
